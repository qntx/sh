This repo builds the QuantX distribution layer:

- `apps/sh` — [sh.qntx.org](https://sh.qntx.org): a build-time-rendered
  static site serving pinned, SHA-256-verified install scripts for qntx
  CLIs (currently `kobe` and `nosfry`). See [Install](/docs/sh/install)
  and [Protocol](/docs/sh/protocol).
- `apps/sk` — [sk.qntx.org](https://sk.qntx.org): a static agent-skills
  discovery endpoint serving locked `SKILL.md` files. See
  [sk.qntx.org](/docs/sk).
- `packages/github` — private `@qntx/github`: the minimal GitHub client,
  stable-release selection, and deterministic lock-file I/O shared by the
  sync tasks in this repo.

Each app's sync task is the only place that calls the GitHub API; the
served site is static files only.
